## 这里是干什么的？

「杂学篇」是创世游戏系列的**生活技能宇宙**：用「老谟（毒舌导师）× 造物主（读者替身）」的苏格拉底对话体，把生活中的一切技能，从最底层**重新发明**一遍。

不背步骤，不抄菜谱。原理到手，万物皆可造。

## 已收录专题 📦

### 🍳 厨艺（第一个！）

> 「造物主饿了，于是世界有了第一顿饭。」

《学做饭》——从「生的和熟的差在哪」这个傻瓜问题出发，一路推到「电磁炉 + 一口锅做出一桌像样的菜」。

- 📖 12 章对话体教材（约 10 万字），每章从反常识问题开始（「水开了不是最猛吗？为什么炖肉要调小火？」）
- 🛠️ 实操手册：39 条技巧 × 理论对照，厨房随手翻
- 🏠 全程限定「宿舍/出租屋简配」，电磁炉 + 一口锅 + 电饭煲就能开干
- 🔥 核心钥匙：**温度决定发生什么，时间决定进行多少**

> **阅读路线**：先读《实操手册》找感觉 → 再读《全书合集》啃原理 → 动手时手册随身。

## 系列特色（不变的灵魂）

- **从零推导**：每个概念都在对话中「重新发明」一遍，不灌输结论
- **问题先行**：问题比答案重要，先「为什么」再「怎么做」
- **宁深勿浅**：宁可一章讲透一个点，不囫囵吞五个
- **翻车是数据**：每章都备好「常见错误」，你踩坑，它兜底
