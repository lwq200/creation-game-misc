## 这里是干什么的？

「杂学篇」是创世游戏系列的**生活技能宇宙**：用「老谟（毒舌导师）× 造物主（读者替身）」的苏格拉底对话体，把生活中的一切技能，从最底层**重新发明**一遍。

不背步骤，不抄菜谱。原理到手，万物皆可造——包括一顿饭，也包括一段关系。

> 老谟的温馨提示：看完这本书，你可能就回不到「装傻」的日子了。

## 已收录专题 📦

### 🍳 厨艺（第一个！）

> 「造物主饿了，于是世界有了第一顿饭。」

《学做饭》——从「生的和熟的差在哪」这个傻瓜问题出发，一路推到「电磁炉 + 一口锅做出一桌像样的菜」。

- 📖 12 章对话体教材（约 10 万字），每章从反常识问题开始（「水开了不是最猛吗？为什么炖肉要调小火？」）
- 🛠️ 实操手册：39 条技巧 × 理论对照，厨房随手翻
- 🏠 全程限定「宿舍/出租屋简配」，电磁炉 + 一口锅 + 电饭煲就能开干
- 🔥 核心钥匙：**温度决定发生什么，时间决定进行多少**

> **阅读路线**：先读《实操手册》找感觉 → 再读《全书合集》啃原理 → 动手时手册随身。

### 💬 沟通（第二个！）

> 「造物主吃饱了，想跟人好好说话了，于是世界有了对话协议。」

《如何谈恋爱与人沟通》——从一句「你总是迟到」怎么把天聊死出发，一路把沟通拆成一台收发机：对话 = 编码-解码，评判 = 噪声，感受 = 信号，需要 = 协议，冲突 = 拥塞崩溃。**九章读完，你就是自己的协议工程师。**

- 📖 9 章对话体教材，三部递进：语言的失真（物理层）→ 认识彼此（操作系统层）→ 冲突与经营（应用层）
- 🗣️ 每章 6-8 轮「老谟 × 造物主」对话 + 严格化走廊（定义 → 定理 → 证明 → 反例）+ 沟通训练场大题
- 🧭 学派中立：NVC vs Maslow、Ekman vs Barrett、依恋可塑之争……分歧一律显式标注进路，绝不把单一视角当唯一真相
- 🔑 核心钥匙：**沟通不是玄学，是可以被建模、实现、验证的系统**
- ✅ 三专家评审闭环：严格性 / 习题数值 / 历史工程，全部过关

> **阅读路线**：先读《蓝图v0.1.md》看全书结构 → 按章序从第01章开推 → 每章先跟造物主走完对话再进走廊，最后去训练场动笔。

## 系列特色（不变的灵魂）

- **从零推导**：每个概念都在对话中「重新发明」一遍，不灌输结论
- **问题先行**：问题比答案重要，先「为什么」再「怎么做」
- **宁深勿浅**：宁可一章讲透一个点，不囫囵吞五个
- **翻车是数据**：每章都备好「常见错误」，你踩坑，它兜底
