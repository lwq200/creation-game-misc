## 系列特色

- **从零推导**：每个概念都在对话中「重新发明」一遍，不灌输结论
- **问题先行**：每章从一个反常识问题出发（「水开了不是最猛吗？为什么炖肉要调小火？」）
- **宁深勿浅**：每个知识点讲深讲透，让读者能「亲手做出来」
- **实操环境真实**：所有技巧都在宿舍/出租屋「电磁炉 + 一口锅」条件下成立
