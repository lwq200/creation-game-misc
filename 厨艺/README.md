# 《学做饭》· 创世游戏系列 · 苏格拉底对话体教材

> 毒舌导师「老谟」× 读者替身「造物主」一问一答，从零推导烹饪原理。
> 这本书不教你任何一道菜，但读完你能自己造菜——因为懂原理的人，不需要菜谱。

**成书信息**
- 读者画像：完全厨房小白（从未独立做过一顿完整饭菜）
- 实操环境：宿舍/出租屋简配（电磁炉 + 一口锅 + 电饭煲）
- 篇幅：一册 12 章，约 9.5 万字
- 方法：每章从「反常识问题」出发，造物主在老谟逼问下自己推出结论
- 结构：对话引擎（原理推导）→ 严格化走廊（定义/定理/证明/反例）→ 实操训练场（动手题）

## 阅读建议

1. **按顺序读**：全书是一条认知链——热（1-4）→ 味（5-8）→ 手（9-12），每章结尾预告下一章的问题，串读体验最佳。
2. **动手跟着做**：每章「实操训练场」有 2 道动手题（含完整分步解答），请准备电磁炉、一口锅、基础食材后边读边做。
3. **翻车是数据**：书里所有「常见错误」都是造物主替你踩过的坑。你做失败了，对照「常见错误」找原因，就是一次成功的推导。

## 章节内部结构

每章统一为 10 个板块：核心认知 → 引子 → 对话引擎 → 严格化走廊 → 知识点总结 → 实操训练场 → 向导便签 → 造物主手记 → 自测题 → 预告（终章为「全册收束」）。

## 关于「创世游戏」系列

本书是「创世游戏」系列教材之一，该系列以苏格拉底对话体写作技术/教育类书籍，核心原则：
- **从零推导**：每个概念在对话中「重新发明」一遍，不灌输结论
- **问题先行**：问题比答案重要
- **宁深勿浅**：每个知识点讲深讲透，让读者能「亲手造出来」
- **意义来自约定**：底层规则是约定，不是天经地义

系列已出版：《从二极管到大模型》《数学基础》（7 册）等。
